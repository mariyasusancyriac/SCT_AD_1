# Calculator App

This is a simple calculator Android application built using Kotlin and Jetpack Compose. The app performs basic arithmetic operations with a clean and user-friendly interface.

## Features

- Basic operations: Addition, Subtraction, Multiplication, Division
- Real-time calculation (result updates while typing)
- Continuous calculations (chain operations)
- Displays current expression on top
- Limits decimal values to 6 places
- Full-screen UI layout

## Tech Stack

- Kotlin
- Jetpack Compose

## How to Run

1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle
4. Run on an emulator or physical device

## Project Structure

- `MainActivity.kt` → Entry point of the app
- `CalculatorScreen.kt` → UI and logic for calculator
- `ui/theme` → App theme
